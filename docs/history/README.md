# Registros históricos

Handoffs preservam o estado observado em suas datas. Caminhos, preferências,
resultados e pendências podem ter sido substituídos. Não são instruções atuais.
As referências vigentes estão em `AGENTS.md` e `docs/context/`.

Na reorganização de 2026-11-06, `prototypes/pixel3d/` passou a `src/game/`.
O 2D foi isolado em `legacy/2d/`; o framework foi arquivado em `tools/studio/`.
IDs, saves e lógica de gameplay foram preservados. O diário local anterior está
em `production/session-logs/` (não versionado).
