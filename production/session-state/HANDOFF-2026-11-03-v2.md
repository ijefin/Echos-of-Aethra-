## 2. COMO TRABALHAR COM ESTE USUÁRIO (obrigatório)
1. Avalia **jogando**. Toda mudança visível: rodar → print (`--shot` ou ferramentas em `tools/`) → olhar → corrigir → **abrir o jogo para ele** (em segundo plano). Sem print visto, não diga que ficou bom.
2. Poucas perguntas. Decida o técnico, conte o que escolheu. Pergunte só o que é dele (história, rumo, instalar coisas).
3. Respostas curtas em PT-BR, links clicáveis, o que mudou / o que ver / o que falta.
4. Seguir `design/art/pixel3d-style-guide.md`. **Não** voltar a 2D. Construir em cima do aprovado.
5. **NADA de texto genérico/tutorial na tela** (memória `no-meta-ui-text`): sem "aperte Q", "libera no nível 2", "mana insuficiente", "tocha 1/3", teclas em objetivos, soluções de puzzle escritas. NPC só conta **história**, falando **sobre a cabeça** (estilo Tibia), nome só quando o jogador está perto. Feedback = visual (cadeado/recarga no HUD, barra de mana piscando, efeitos).
6. Referência constante dele: **Tibia** (textos com contorno, nomes de monstro na cor da vida + barrinha, XP branco subindo, mensagem central ao subir de nível, chat com abas, andares, bolsas, uso de itens).

8. Regras de `CLAUDE.md`: sem commit sem pedido; perguntar antes de gravar em `design/`; protótipo não vira produção (reescrever em `src/` depois).
