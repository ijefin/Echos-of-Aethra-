# Arquivo histórico

O jogo oficial está em `src/game/`. Não é necessário ler este diretório para
trabalhar nele. `.gdignore` impede importação pelo Godot; `.ignore` evita buscas
rotineiras. Arquivos foram preservados, não apagados.

- `2d/`: jogo anterior, assets, ferramentas, especificações e rascunhos associados.
- `experiments/`: combate web e showroom de rig anteriores à adoção do 3D.

Este é um arquivo de referência, sem garantia de execução isolada. Reativar o
legado ou portar ideias dele é uma tarefa explícita, não etapa de contextualização.
